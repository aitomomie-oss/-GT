# ダブルクリックで更新する

最初の1回だけ、更新ファイルが入った最新版ZIPをダウンロードしてください。

1. [最新版ZIP](https://github.com/aitomomie-oss/-GT/archive/refs/heads/main.zip)をダウンロードします。
2. ZIPを右クリックし「すべて展開」→「展開」を押します。
3. 展開したフォルダを開き、**「自動更新.bat」**をダブルクリックします。拡張子が隠れている場合は「自動更新」と表示されます。
4. フォルダ選択の画面で、**今まで使っていた古いアプリのフォルダ**を選びます。`app.py` があるフォルダです。今ダウンロードした新しいフォルダと間違えないでください。
5. 古いアプリを停止してから、画面の「OK」を押します。
6. 更新中の画面が終わるまで待ちます。ダウンロードできない場合は、ブラウザーでダウンロード済みの最新版ZIPを選びます。
7. 自動的に開いた新しいフォルダの **「起動.bat」**をダブルクリックします。これからはこの新しいフォルダを使います。
8. 今までの資産が表示されることを確認してください。表示されない場合は追加登録せず、アプリを停止し、元のアプリを使ってください。

## 自動で行うこと

- SQLiteの整合性確認とバックアップ（WALの確定済みデータを含む）
- 最新コードの取得と別フォルダへの展開
- 元の資産DBと `.streamlit/secrets.toml` のコピー
- Python 3.12仮想環境の作成とライブラリのインストール
- 新しいフォルダを開く（アプリの起動は本人が行う）

元のアプリは上書き・削除しません。元のフォルダの隣に `MY_AI_ASSET_backup_日時` と `MY_AI_ASSET_日時` を作ります。バックアップのsecrets.tomlにはAPIキーが含まれます。バックアップもPC内で保管し、GitHubやチャットへアップロードしないでください。

`local_data/assets.db` と旧形式 `data/assets.db` のどちらかを使えます。両方ある場合や独自DB設定がある場合は、使用中のDBを選ぶ画面を表示します。不明ならキャンセルしてください。DBを発見できなかった場合は、新規利用かを確認してから進みます。

## 更新できない場合

Python 3.12とPython Launcher、インターネット接続、書き込み権限、十分な空き容量が必要です。PythonがないPCには、この更新ファイルだけでPythonを自動インストールしません。

GitHubへの認証情報を入力・保存する機能はありません。非公開リポジトリなどで自動取得できなければ、GitHubにログインしたブラウザーからZIPを保存して選んでください。

途中で失敗しても元のアプリは変更しません。作成途中のフォルダからは起動せず、元のアプリを使用してください。新しい版で入力した変更は古い版へ自動反映されないため、新版を使い始めた後は新旧を交互に使わないでください。

## 検証範囲

バックアップ、秘密設定のコピー、WAL、更新失敗、ZIPの危険なパス・実データ混入の拒否、更新の独立性をLinux上の自動テストで検証。Windows実機でのダブルクリック、フォルダ選択画面、インストール実行は未検証です。
