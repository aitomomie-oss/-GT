# 評価履歴機能：開発コピーでの適用

## 対象と方式

対象は `%USERPROFILE%/MY_AI_ASSET_Development/MY_AI_ASSET_NEXT_dev_20261020_071809_276252_6e01f286`。Windowsで修正後の204テストが成功した開発コピーです。Downloadsの元アプリ、初回バックアップ、GTのZIPは操作しません。

[prepare_evaluation.py](prepare_evaluation.py) は、元の開発コピーも更新せず、同じ親フォルダーへ `MY_AI_ASSET_NEXT_evaluation_dev_<日時>_<識別子>` を作ります。DBを移行するのは新しいコピーだけです。準備時点のデータのコピーなので、その後に元アプリへ登録した内容を自動統合しません。

この段階は既知の評価履歴機能の導入です。アプリ名称の変更、新しい投資戦略、配点変更、有料プランへの切替は含みません。

## 追加される機能

- 8番目の「検証・評価履歴」画面。
- 評価時点の入力データ、計算根拠、点数または保留理由、基準日、取得日時の保存。
- 同一内容の重複保存抑止、前回との比較、公式資料との手動照合・訂正履歴、CSV/JSON出力。
- 追加テーブル `evaluation_snapshots` と `data_verifications`、対応する2索引。

基準のコードは固定コミット `0eaedc06b674c7b813580f030c6b9f1802b04844`。API取得、欠損・遅延データの補完、過去の利益のバックテスト、発注は行いません。詳細は新コピー内 `docs/evaluation_audit.md` を参照してください。ただし同文書の通常版更新手順は今回使用せず、本手順の専用ランチャーを使います。

## 安全確認

1. 開発フォルダー名・親・開発起動バッチと、コード/設定/架空サンプル115ファイルのSHA256を照合。未知のPythonファイルや改変は保留します。
2. 固定コミットの11ファイルをHTTPSで取得し、全SHA256を照合してからローカル準備へ進みます。
3. 元開発コピー内 `backups/before_evaluation_<日時>_<識別子>` へコード・設定とSQLiteオンラインバックアップを保存。既存の秘密設定がある場合はこの私的な回復用バックアップにだけコピーし、新アプリには持ち込みません。秘密値を報告書や出力へ書きません。
4. 新コピーへDBを複製し、新コピーのコードだけで移行。元開発コピー/元アプリのDBへ新しい接続初期化を行いません。
5. 整合性・外部キー、既存の全スキーマ定義と全行（重複を含む）の一致、新しい2テーブル/2索引だけが追加されたことを検証。未知の既存表・ビューも維持します。値の比較結果のみ出力し、実際の明細や行ハッシュは出力しません。
6. 新コピーの全237テストを自動実行。テスト前後にコピーDBと元開発DBが変わらないことを確認します。
7. 全確認が成功した場合だけ `評価履歴_開発用起動.bat` を生成します。失敗した新コピーからは起動せず、元開発コピーを引き続き使います。

`tools/windows_update.py` とそのテストのWindows修正は維持されます。元開発コピーのコード・DB・設定・起動バッチは置換しません。新コピーに.venvは複製せず、確認済み元開発コピーのPython環境を共有します。依存関係は変更しません。元開発フォルダーは削除・移動しないでください。

## Windowsでの実行と結果

開発用アプリを起動しているPowerShellでCtrl+Cを押して停止してから、テストを実行した別のPowerShellで、SHA256確認済みの `prepare_evaluation.py` に確認済み開発フォルダーの絶対パスを渡します。

成功時は `NEXT_EVALUATION_READY`、新フォルダー、バックアップ先、通常は `Tables: 31 -> 33` が表示されます。テスト237件の成功を確認してください。未知の既存テーブルがある場合は表数が多くなります。失敗時は `NEXT_EVALUATION_STOPPED` の固定理由を確認し、元アプリやバックアップを削除しないでください。

準備後もアプリは自動起動しません。出力された新フォルダーの `評価履歴_開発用起動.bat` から起動します。接続先はユーザーPCの `http://127.0.0.1:8506`。背景API更新は無効、DBは新コピーの絶対パスです。最初に保有資産・積立プランと追加画面を確認します。データ更新や本番運用への切替はこの段階で行いません。
