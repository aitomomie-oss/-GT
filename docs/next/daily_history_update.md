# 保存済み日別データ・照合用CSVの追加

## 背景と追加内容

Windowsで評価履歴画面、保存した履歴、公式資料との照合画面の表示をユーザーが確認しました。一方、SBI証券のチャートから指定日の終値を数値で確認できず、独立した公式値との照合は保留しています。画面表示やアプリ内データの一致を精度検証の完了とは扱いません。

「検証・評価履歴」に「日別データ・照合用CSV」を追加しました。保存された価格を日付で選び、未調整終値・調整後終値・出来高・出典・取得成功日時・取得状態・遅延の有無を確認できます。表示中の行をCSV出力でき、独立確認値の記入欄は空欄です。既存の手動照合がある場合は、同じ履歴/基準日/未調整終値だけに最新の確認値・判定を別列で表示します。

この機能は保存済みデータを読むものであり、別の公式資料を自動取得したり正しさを認証する機能ではありません。保存されていない日付や欠損値は補完せず、未照合/比較保留を一致へ変更しません。

## 変更ファイル

- `src/ui_evaluation_audit.py`：新タブ、日付フィルター、表示中のCSV出力。
- `src/services/daily_history.py`：評価履歴を読み取る日別一覧・CSV生成。DBへの書込・HTTPなし。
- `tests/test_daily_history.py`：10件の回帰/画面検証。
- `docs/daily_history.md`：操作方法と照合の限界。

アプリコードの固定参照は `4986f033cd4cbc59484e1ebaab34a4283bb6d767`。保有資産、積立、損益、API認証、DBモデル・接続・既存の評価保存形式は変更しません。依存追加とDB移行はありません。

## Windowsへの適用

[apply_daily_history.py](apply_daily_history.py) は次の確認済み開発コピーだけを対象とします。

```text
%USERPROFILE%/MY_AI_ASSET_Development/MY_AI_ASSET_NEXT_evaluation_dev_20261020_081047_0f20662e
```

専用8506番のアプリを起動したPowerShellでCtrl+Cを押し、停止してから実行してください。Downloadsや旧開発コピーへ適用しないでください。

1. 対象名・専用起動バッチ・基準のapp/model/session/UIのSHA256と新規ファイルの不存在を確認。
2. 固定コミットの4ファイルを取得し、全SHA256を照合。
3. 対象内 `backups/before_daily_history_<日時>_<識別子>` へSQLiteオンラインバックアップとコード・設定・起動バッチを保存。秘密設定がある場合、私的な回復バックアップにだけ複製し、テストコピーには渡しません。
4. 別の `test_copy` に変更を適用し、現在のPython環境で全247テストを実行。親フォルダーのpytest設定を引き継がないよう、既存と同じテスト設定をコピー内に明示。
5. コピーDBと元DBの全定義・全行（重複を含む）がテスト前後で同じことを検証。実値や行ハッシュを出力しません。
6. 成功時だけ対象の4ファイルを差し替え、再び全SHA256と元DBの不変を確認。途中失敗なら差し替えたコードを戻し、バックアップは保持。

成功時は `DAILY_HISTORY_READY`、バックアップ先、`Database / settings / launchers: NOT CHANGED` が表示されます。同じ修正の再実行は `DAILY_HISTORY_ALREADY_APPLIED` となり、新たな適用や取得はしません。元DBへのアプリ初期化は行いません。

その後、同じ `評価履歴_開発用起動.bat` で再起動し、ユーザーPCの `http://127.0.0.1:8506` を開きます。「検証・評価履歴」で保存済み評価を選び「日別データ・照合用CSV」を押してください。CSVはご自身のPCへ保存します。編集したCSVの再取込は未実装です。
