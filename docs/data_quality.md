# データ品質サマリー

「検証・評価履歴」画面の上部に表示します。銘柄コード・評価ルールごとに最新の保存評価を1件選び、保存時の不足・失敗と、今日時点の基準日の古さを確認します。現在の全候補・全キャッシュを再評価する画面ではありません。

- 対象評価：銘柄・ルールの組ごとの最新記録。保存していない銘柄は対象外。
- 指標不足：保存時の6評価軸のいずれかが欠損。0点は欠損と区別。
- 期限超過：価格・PER/PBR等の倍率基準日が7暦日超、財務基準日が365暦日超。基準日不明・未来日は期限内とせず表に理由を表示。期限内でも正確性や評価への利用可否を保証しません。
- 取得失敗：保存時の価格API・財務API・手動財務の直近状態に失敗を含む記録。API利用制限など既知の理由を固定の日本語で表示。認証値や不明なエラーの原文は表示しません。
- 未照合・比較保留：保存値のある項目について確認記録がない、または最新の照合が比較保留。欠損値は未照合に数えません。
- 差異あり：最新の手動照合記録に差異がある項目を含む記録。

件数は評価単位で、1件が複数の区分に該当するため合算できません。数値のある項目の確認状況は表の項目数で確認します。訂正後の最新の照合だけを使い、別の日付・別の保存評価の照合を流用しません。利用者による「一致」「許容差内」はアプリが資料の真正性を確認した結果ではありません。

「品質の確認対象」で絞り込み、理由と優先確認事項を見られます。「表示中の品質サマリーをCSVで保存」はUTF-8 BOM付きで、出典確認など次の作業を記録するための出力です。表示の絞込はデータ削除や修正を行いません。

現在のローカル更新ジョブに失敗がある場合は、保存評価とは別集計で種別・理由・件数を表示します。キューを追加したり再試行したりすることはありません。

APIキーを読み込まず、通信・DB書込・評価式や保存済み点数の変更を行いません。従来のホームを開いた際の評価履歴自動保存は従来どおりです。投資信託・米国株の別評価エンジンや未保存銘柄の品質調査、公式資料の自動照合、過去の投資成果の検証は含みません。
