# Phase 2照合と計画

Phase 1の24テスト、6画面、直接残高DB/計算を維持する。
実SBI CSV・実PayPay PDFは未提供。SBI専用の確認済み固定列形式は作れないため、実アップロードのヘッダーを表示して利用者が列と値を明示対応付けする汎用アダプターを実装する。検証は「架空」と明記したCSV/PDFで行い、実形式を検証済みとは報告しない。

1. ファイルサイズ/列/日付/通貨を検証し、SBIの確認プレビューを実装。
2. 取引履歴・ファイルハッシュ・行識別・エラー件数を保存。全件トランザクション、重複防止、バッチ取消/復元、修正履歴。
3. PayPayテキストPDFの抽出補助と編集可能プレビュー、抽出不能時の手入力。同様の確認/保存経路を使う。
4. 完全な履歴であることを利用者が確認した取引のみ参考残高・移動平均原価を算定。現在価格/評価為替は別入力。直接残高があればそちらを優先し、加算せず照合差を表示する。
5. 予算、集中、口座跨ぎ重複、費用とデータ不足を理由付きで分析。
6. 既存24件を変更せず維持し追加テスト。Windows実機がないためWindows検証は未実施として残す。

取引CSVと直接残高CSVは別経路。取引の登録から手入力現金や外部拠出額を書き換えない。取消は取引の有効性だけを切替え、直接残高・過去スナップショット・口座参考値には触れない。
