# AI銘柄探索：使い方と対応範囲

既存6画面に「AI銘柄探索」を追加。候補カタログ・観測データ・ウォッチリストは保有商品テーブルから分離しています。登録・比較・削除・API更新を行っても、保有数量、取得原価、総資産、現金、取引明細は変更しません。発注機能はありません。

## 操作

1. 「候補銘柄を登録」でコード/管理コード、名称、商品種別、通貨を入力。
2. 詳細の「候補データの登録・更新」で価格/基準価額、費用、投資対象、リスク、財務、取扱条件を出典と基準日付きで登録。
3. 登録済み候補を名称・コード・商品種別・地域・リスク・NISA条件・未保有/ウォッチ条件で検索。評価済みは点数順、重要情報がない候補は評価保留。
4. 詳細で点数の内訳、根拠、注意事項、保有eMAXIS Slim S&P500との違い、少額購入条件を確認。
5. ウォッチリストはメモ/優先度の編集と削除に対応。候補自体の削除とは別です。
6. 2〜6候補を比較できます。異なる商品種別は配点が違うため、点数だけで商品間の優劣を断定しないでください。

検索対象は登録済みカタログです。日本株は任意のJ-Quants銘柄一覧から候補を追加できます。全世界の全銘柄を自動収集する機能ではありません。
付属の探索サンプルは5銘柄すべて架空。実際のSBI取扱い・NISA適格性・企業財務ではありません。サンプルは候補カタログが空の場合だけ投入できます。

## 比較基準と二重計上防止

利用者指定の `eMAXIS Slim 米国株式（S&P500）` を比較基準とします。名称に含まれるS&P500という参照指数だけを既知として扱い、保有数量・取得原価・最新コスト・構成比を捏造しません。この比較基準を保有資産DBへ自動登録しません。

登録済みの保有資産とはコード/名称で同一候補を確認し、未保有フィルターで除外します。地域/分類と保有商品種類からの構成重複は「可能性」で表示し、正確な組入比率として扱いません。ベンチマークが同じ、または米国/全世界という分類の場合はS&P500との重複確認を促します。
保有商品の年率費用が商品設定に入力されていれば候補との参考差を表示しますが、確認日未登録のためスコアへ自動反映しません。

## 予算と積立予定

「積立プラン」下部で口座・商品名・予定日・予定額を登録/編集/取消できます。SBI NISAを初期口座として優先します。固定の個別株配分を押し付けません。

残予算 = 月予算と検討上限の小さい方 − 集計指定済み購入実績 − 未実施積立予定。

初期月予算7,500円、標準5,000〜10,000円を維持します。最低購入金額、通常売買単位、1株/1口購入、金額指定購入は利用者確認済みの条件だけを使います。未確認なら要確認/判定保留。試算は手数料・為替スプレッド・将来価格変動を含みません。

予定の実施を確認した場合、同月の手入力実績へ新規登録、または同日同社同額の既存手入力実績へ紐付けできます。完了後は予定と実績を二重に差し引きません。紐付いた実績を削除すると予定を未実施へ戻して予約額を維持します。
取込済み取引への自動突合せは未実装。同日同額の取込実績があれば新規実績の重複登録を止め、利用者が予定の扱いを確認します。未突合せの予定は保守的に予約額として残ります。

## データの保存・鮮度

各観測にデータ基準日、提供元、取得日時、遅延フラグ、成功/失敗状態を保存。API銘柄一覧から登録した名称/コードも、元の基準日・提供元・取得日時を保存します。時刻の保存はUTC、探索画面は日本時間で表示。
最新の取得が失敗した場合は、前回成功値を参照用に保持する一方、判定は保留にします。取得日時だけを新しくして古い基準日を最新扱いしません。
識別コード・名称・種別・通貨を変更した場合は、前の商品データで評価しないよう再確認状態へ移します。

既存DBへの初回追加前に `.pre-discovery.bak` を保存し、新規テーブルと積立予定用の追加列を作成します。既存テーブルを削除・初期化しません。バックアップはGit/配布ZIPから除外します。
WindowsでDBファイルが不要に開いたままにならないよう、移行用SQLite接続も明示的に閉じます。

## 対応済み/未対応の取得経路

| 対象 | 対応済み | 未対応・未検証 |
|---|---|---|
| 日本株/国内ETF | J-Quants V2銘柄一覧、日足、調整後終値からの変動率/最大下落。公式形式によるモック検証 | 認証付きライブ接続、財務・PER/PBR等の自動取得 |
| 投信/ETF | 手入力による基準価額・費用・分類・リスク・取扱条件更新 | 全商品の無料データ源、運用会社サイトからの自動収集 |
| 米国株 | 手入力、将来拡張用の独立アダプター | 実データAPI接続 |
| NISA/SBI | 出典・基準日付きの利用者確認入力、未知/古さ/取扱不明の警告 | 公式対象一覧/販売会社取扱一覧との自動同期 |

本開発環境ではJQUANTS_API_KEYが未設定。認証なしのAPI疎通も通信エラーとなったため、実際の契約・認証・配信データによる取得は未検証です。APIキー値をチャット・DB・Gitへ保存しないでください。
WindowsでのAPI設定/更新手順はwindows_research.md、評価式はdiscovery_scoring.md、公式プロトコルの確認箇所はjquants_v2.md。
