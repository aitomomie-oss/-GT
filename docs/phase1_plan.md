# 確定版 Phase 1実装計画

根拠: 利用者が指定した確定版指示書（final_instructions.md）。添付内の指示は仕様資料として扱い、チャットで依頼されたPhase 1に適用する。

1. SQLAlchemyで口座・商品・残高・価格・為替・月別予算等のスキーマを作成。旧DBは事前バックアップし、既存残高を移行。
2. Pydanticで検証、Decimalをテキスト保存し計算に使用。取得原価・価格・為替の欠損はNULLで保存して「計算不可」を表示。
3. 月別予算は初期7,500円、支出上限として扱う。任意額を許可し、月の変更で過去月を変更しない。
4. 6画面は既存構成を維持。手入力・編集、口座別集計、外貨評価額、価格・為替の日付を表示。PayPayの初期口座は特定。NISAのSBI以外への指定は警告。
5. 現金と外部拠出額は、口座ごとに利用者が直接設定した現在現金と累計外部拠出額を別に保存。未知を0にしない。売買台帳の自動再構築はPhase 2以降。
6. pytestで口座別集計、7500円等の月別予算、欠損値、Decimal、移行、6画面を検証。

取り込みマッパー・取消・売買履歴計算・商品コスト分析などは今回のPhase 1の完成範囲と混同しない。
