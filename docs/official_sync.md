# 公式一覧同期・取引停止検知・配当利回り

## 追加した内容

1. JPX公式資料からコードと停止状況を読み、銘柄探索・購入判定へ反映します。停止中、再開予定、解釈不明の停止情報は購入前の確認対象となります。日時の記載だけで再開済みと判断しません。以前の停止情報が残った状態で取得に失敗した場合は、停止なしに戻しません。
2. 金融庁のつみたて投資枠、公式の成長投資枠対象一覧を分けて同期します。銘柄コード、ISINまたは一意の完全一致名称で照合します。部分一致や一覧への非掲載だけで適格性を推測しません。SBI取扱いとNISA残枠は別途確認します。
3. J-Quants V2の公表済み通期年間配当（DivAnn）と日足終値（C）から実績参考配当利回りを計算します。財務を取得すると計算処理も実行します。計算結果には配当期間、開示日、株価基準日、取得日時、出典、計算式と遅延区分を表示します。

## アプリでの操作

1. アプリを更新する前に停止し、実データのDBをコピーして保管します。更新時には `.pre-official-sync.bak` も自動作成します。
2. 「AI銘柄探索」→「日本株の自動探索」→「公式一覧の自動同期・取引停止検知」を開きます。
3. 「同期する公式資料」を選び、対応する公式資料のURLを入力します。画面内に案内ページの例があります。資料の対象区分を確認してチェックし、「公式資料を設定して同期」を押します。
4. 設定後はアプリを開いて使う際、停止情報15分・NISA一覧24時間の間隔で期限切れ資料を再取得します。アプリを閉じている間は実行しません。「今すぐ更新」も利用できます。
5. 取得状態が `ok` か、資料基準日と取得日時が妥当かを確認してください。`error` は取得または形式の確認に失敗した状態です。
6. 配当利回りは個別銘柄の「財務・指標を取得」で自動計算されます。「配当利回りを再計算」でも更新できます。古いバージョンで保存した財務には必要な原データがないため、先に財務を再取得してください。

## 対応形式・制限

- HTML表、CSV（UTF-8/CP932/UTF-16）、XLSX、文字抽出可能なPDFに対応する読み取り処理を追加しました。これは任意の公式レイアウトへの無条件対応ではありません。認識できる商品名・コード・状態等の見出しと、明示された資料更新日/基準日が必要です。
- 案内ページに新しいCSV/XLSX/PDFへのリンクが1つだけ確認できる場合は追跡します。複数の資料が該当する場合は、正しい対象区分のファイルURLを指定してください。自動で資料の対象区分を推測しません。
- 金融庁/JITA/JPXのHTTPSだけに接続し、リダイレクト、認証情報入りURL、クエリー付きURLは拒否します。証券会社ログインやAPIキーは送信しません。取引停止はJPXのみ、つみたて対象資料は金融庁のみを受け付けます。
- ダウンロード20MB、XLSX展開合計60MB、PDF200ページ、参照ファイル最大5件に制限。数式セルを値として採用しません。画像PDF、旧XLS、JavaScriptのみで提供されるデータ、認識できない表は更新失敗として保持します。
- 停止資料は当日かつ取得15分以内、NISA対象資料は基準日31日以内かつ取得24時間以内を有効情報として扱います。資料の基準日がない場合はHTTP取得日で代用しません。
- JPX資料の対象外市場と、一覧にない銘柄は停止状態「未確認」です。これを売買可能の保証には使いません。停止検知はリアルタイム配信ではなく、設定した公式資料の掲載範囲と更新間隔に依存します。
- NISA公式資料への非掲載は「不明」。非対象商品の自動判定や、個人口座の残枠の取得は行いません。名寄せが曖昧な商品は人による確認が必要です。

## 配当利回りの計算基準

基本式: 公表済み通期1株年間配当 ÷ 取得終値 × 100。

配当年度内の分割・併合は年間配当の株数基準が混在する可能性があるため、計算を保留します。配当年度後の分割・併合は、期末株数基準の年間配当へ日足AdjFactorの積を掛けて取得終値の株数基準へ合わせます。調整係数が欠けている場合や、必要な期間の株価を取得できない場合は推測しません。明示された配当0円は利回り0%、欠損は不明です。

これは公表済み決算期の実績を使う参考利回りで、今後受け取れる配当や会社予想利回りを意味しません。特別配当、会計変更、分割に関する会社資料も確認してください。無料プランの遅延値は過去の参考値として表示し、現在の評価点・購入可否には使用しません。失敗時は前回結果を参考用に残し、現在値として再利用しません。
