# 計算仕様（Phase 1・2）

- 外貨時価 = 数量 × 現在単価 ÷ 価格単位
- 円評価額 = 外貨時価 × 評価日に対応する為替
- 含み損益（参考） = 円評価額 − 円建参考取得原価
- 損益率 = 含み損益 ÷ 参考取得原価 × 100（取得原価0は未定義）
- 円建平均取得単価 = 参考取得原価 ÷ 数量 × 価格単位（数量0は未定義）

投信価格は1万口、株式は1株、ETFは1口。米国株はUSD、日本株はJPY。JPYの為替は1です。
USD時価と円換算評価額を別表示し、過去の取得時為替がない場合に外貨取得単価を逆算しません。
為替未取得、価格未取得、USDの価格と為替の適用日不一致では円換算不可。取得原価が不明なら損益不可。
集計内に1件でも必要な値が不明なら、その集計も不明です。既知の部分だけを総資産と表示しません。

総資産は保有評価額＋口座現金。現金未入力なら総資産は未取得とし、保有評価額は独立表示。
外部拠出額は外部入金−外部出金、口座間振替を除外。Phase 1では口座ごとの手入力参考値。
参考取得原価や購入額合計を外部拠出元本と呼びません。運用損益の累積は台帳未整備のため未算定です。

口座・商品が同じ場合は最新評価日だけを集計。過去の残高は加算しません。取引由来の参考残高は別経路で算出し、直接残高を優先して二重加算を防止します。

月別予算は初期7,500円。5,000〜10,000円を標準とし任意の非負整数を許可。残予算＝対象月予算−対象月の実績支出。
積立支出は保有残高・現金・外部拠出額を自動更新しません。日付は日本時間基準です。

計算・保存はDecimal/TEXT。上限10^18、小数点以下18桁、計算精度128桁。平均単価や利率等の循環/無理数には有限精度が必要です。
シミュレーションは40桁のDecimalで月率 `(1+r)^(1/12)-1`、月末に `残高×(1+月率)+積立額`。
これは一定利回りの仮定で、価格予測ではありません。税・費用・為替・インフレは考慮しません。

架空3商品の評価額82,500円、取得原価74,000円、含み損益8,500円。現金・外部拠出は未取得です。
