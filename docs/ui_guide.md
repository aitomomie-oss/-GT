# 見やすくなった画面の使い方

今回の更新は画面と操作の改善です。資産データ・予算計算・評価の配点・APIの契約を変更しません。有料プランへの切り替えも行いません。

## 更新して開く

1. 今使っているアプリを停止します。
2. **自動更新.bat** を開き、今まで使っていたアプリのフォルダを選びます。
3. 完了後に開いた新しいフォルダの **起動.bat** をダブルクリックします。
4. ホームで以前の資産が表示されることを確認します。

自動更新ファイルがない場合は [最新版ZIP](https://github.com/aitomomie-oss/-GT/archive/refs/heads/main.zip)を保存して「すべて展開」してください。[更新の詳しい手順](windows_auto_update.md)

## ホーム

資産の金額をカードで表示します。「未登録」「未確定」は0円ではありません。現金の登録などが必要な項目には説明を付けています。

- **積立実績差引（予定前）**：従来の積立実績だけを差し引いた額です。
- **投資可能残額（候補用）**：積立予定とその他の購入実績も考慮した額です。「残予算の内訳を確認」を開くと計算の内訳が見えます。

候補欄を3つのタブに整理しました。

### 候補を探す

会社名やコードで検索できます。購入単位・商品種別・未保有フィルターも利用できます。

「候補の根拠・注意点を見る」で銘柄を選び、**選択した候補の詳細・ウォッチ登録**を開きます。

- **概要・ウォッチ**：参考価格・基準日・評価保留の理由を確認し、メモを付けてウォッチへ保存します。
- **評価の根拠・リスク**：点数、配点、計算式、価格変動リスクを確認します。
- **購入条件・出典**：NISAや購入条件を確認します。費用の確認値もここから登録できます。

更新で一覧の並びが変わっても、選択中の銘柄と編集中のメモを維持します。

銘柄・購入単位を切り替えると、費用欄はその銘柄・購入単位の登録値を表示します。前の銘柄の入力を無条件に引き継ぎません。ウォッチメモも銘柄ごとに扱います。

### データ更新の状況

更新済み・更新中・制限待ち・要確認を件数で表示します。更新状態を選ぶと該当する行だけ確認できます。

| 表示 | 意味・操作 |
|---|---|
| 更新済み | 取得処理が完了。価格の新しさは別途基準日で確認 |
| 更新中 | 自動処理中。画面の操作を続けられます |
| 更新待ち | 未取得または期限切れ。順番に更新 |
| 制限待ち | API回数制限。連打せず自動再試行を待つ |
| 要確認 | 通信・契約範囲・設定などの説明を確認 |

`price`、`finance`、`dividend` は「株価・出来高」「財務・指標」「配当利回り」に変更しました。`rate_limit` 等の診断コードは、必要な場合だけ「詳細な診断コードを表示」で確認できます。

ホームの候補欄は30秒ごとに表示を再読込します。API通信の間隔やバックオフは変更していません。

### 評価基準

ホームの6項目の配点と計算式をまとめています。欠損を0点扱いしたり、保留の銘柄に仮の点数を付けたりする変更はしていません。

## AI銘柄探索

最初に **日本株の自動探索** が開き、3つのタブが表示されます。

1. **銘柄を探す**：会社名・コード・業種で検索し、一覧の行をクリックすると下の企業詳細が切り替わります。検索結果が少ない場合は表の高さも小さくなります。
2. **予算・NISA**：従来の予算設定とNISA確認値の登録をまとめました。ホームの投資可能額との集計範囲の違いも説明しています。
3. **接続・公式資料**：APIキーの読み込み診断と、NISA・停止情報の公式資料設定があります。キーの値は表示しません。

一覧はコード・企業名・参考価格・株価基準日・価格の種類・評価状態・NISA・保有区分の8項目を基本表示します。未取得値は「未取得」と表示します。以前の全項目は **すべての分析項目を表示** で確認できます。

個別企業の詳細は「企業・価格」「分析・取得データ」「購入条件・試算」に整理しています。「この銘柄をウォッチに保存」で直接登録できます。すでにあるメモや優先度はこのボタンで消しません。

普段は自動更新を使えます。手動の一覧取得が必要なときは **一覧の取得・手動更新** を開き、基準日を確認して「銘柄一覧を取得・更新」を押してください。結果は他の検索操作をしても画面に残ります。

従来の登録候補、編集・削除、比較、ウォッチ絞り込みは、下の **登録済み候補・ウォッチ・比較** に残しています。

## 無料プランでの見方

- **過去の参考価格**は、いま買える価格ではありません。
- **評価保留**は、遅延価格や必要な指標の不足を意味します。取得が終われば必ず解除されるわけではありません。
- **制限待ち**はAPIの利用回数制限です。キー未設定や認証失敗とは区別しています。

今回の変更で過去の価格を最新と表示したり、不足データを埋めたりはしていません。有料プランに切り替えた際の取得設定や権限は別途確認が必要です。
