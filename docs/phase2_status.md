# Phase 2実装結果

## 今回の範囲

ユーザーのPhase 2開発指示と、途中の「取引CSVなしでも初期残高を手入力して開始できること」に対応。
実SBI CSV・実PayPay PDFは未提供。専用の実フォーマットを確認済みとは報告しない。

## 作成・変更したファイル

- src/importers/trades.py、sbi.py、paypay.py: 共通取引検証、実ヘッダーの対応付け、PDF文字抽出・候補提示
- src/services/imports.py、ledger.py: バッチ履歴、重複防止、取消/復元、修正監査、参考移動平均、照合
- src/db/models.py、session.py: 既存DBへの追加列/テーブル、移行前バックアップ
- src/services/portfolio.py、budget.py、analysis.py: 直接残高優先、取引の予算反映、説明付き集中/重複/費用分析
- src/ui_imports.py、pages/2_保有資産.py、4_AI分析.py、6_データ管理.py、src/ui.py: プレビュー・取込管理・初期残高入力
- sample_data/phase2/: 架空CSV/PDFと設定例
- tests/test_phase2.py、test_phase2_ui.py、requirements.txt、READMEと仕様文書

## 完成した機能

SBI CSVの実ヘッダー表示と列・値マッピング、投信/日本株/米国株/ETFのbuy/sell検証、保存前プレビュー、不明項目の表示。
PayPayテキストPDFの抽出補助と編集・確認、画像/暗号化/読取不能の場合の手入力。
ファイルハッシュ、行/取引識別、件数・エラー・登録日時・設定、取り込み単位の取消/復元、取引修正と監査履歴。
完全履歴確認後の参考数量・移動平均原価/売却損益、別入力の現在価格/為替による円評価。
直接残高の優先と照合、類似商品の保留による二重加算防止。取消でも手入力残高・現金・外部拠出額・保存済み履歴を変更しない。
予算、商品集中、口座跨ぎの商品重複、任意登録の年率費用と未入力警告、判定理由・日時・制約の表示/保存。
