# 日別データと照合用CSV

「検証・評価履歴」で評価履歴を選択し、**日別データ・照合用CSV**を開きます。保存時点の日足を新しい日付から一覧表示し、「日付で絞り込む」で1日を選べます。保存していない日付を補完することはありません。

未調整終値・調整後終値・出来高を分けて表示します。取得元・最終取得成功日時・保存時の取得状態・遅延の有無も表示します。画面の保存日時は日本時間、CSVの保存/取得日時はUTCです。数値は文字列として保持し、小数の桁を勝手に丸めません。出来高0と未取得は区別します。価格の欠損、日付不明、同日複数行には注意を表示します。

「表示中の日別データをCSVで保存」は表示中の行だけを、Excel向けUTF-8 BOM付きで保存します。評価履歴ID・銘柄・評価日時・価格基準日・保存値・取得元・取得状態を含みます。表計算ソフトの式として解釈され得る文字列を無害化します。

## 照合との違い

- 一覧/CSVは、すでに選択中の評価履歴に保存された取得値です。最新値の取得や公式資料との自動照合ではありません。
- 同じ取得元の数値を比較しても、独立した確認にはなりません。
- CSVの「独立確認値の記入欄」「確認資料URLの記入欄」は空欄です。アプリの取得値から自動入力しません。
- 同じ評価履歴の未調整終値について、既存の「公式資料と照合」で手動記録した確認値・確認日・判定がある場合は別列に表示します。保存された取得値や調整後終値を書き換えません。他の日付や他の評価履歴に判定を流用しません。
- 最新の訂正記録を使います。異なる基準日や条件未確認なら「比較保留」、未記録は「未照合」です。「一致」は利用者が記録した照合結果であり、アプリが資料の真正性を認証した意味ではありません。
- CSVの編集内容をDBに取り込む機能は含みません。日別の任意の過去日へ一括して公式確認値を登録する機能もありません。

この機能はAPIを呼び出さず、価格キャッシュ・保有資産・積立・評価式・SQLiteスキーマを変更しません。評価履歴に日足がなければ、その旨を表示します。保存前の観測や欠けた株価を再構成することはありません。
