# 架空サンプルのみ

- sbi_fictional.csv: SBIの実フォーマットではない架空取引CSV。投信/米国株にも同じ論理項目を対応付ける設計。
- sbi_mapping.json: この架空CSV用の列/値対応例。実ファイルへの自動適用はしない。
- paypay_fictional.pdf: 標準PDFオブジェクトで生成した英語テキストPDF。PayPayの公式書面様式を模倣したものではない。

株Aの買付10株×100円+手数料10円=原価1,010円、買付10株×200円+10円=2,010円。
合計20株/3,020円、移動平均151円。5株売却×300円−手数料5円=1,495円。
対応原価755円、参考売却損益740円、残り15株の原価2,265円。
税額0はこの架空例の設定であり、実際の課税率や制度ではない。

米国株のPDF例は2株×100USD+手数料1USD、約定時USD/JPY150円。取得原価は30,150円。
現在株価/評価為替はPDFの取引値で代用せず、保有資産画面で別に入力する。
